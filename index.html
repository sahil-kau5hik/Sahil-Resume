Projects

🤖 AI / RAG Project

AskBabbar — RAG-Based DSA Learning Assistant

An end-to-end Retrieval-Augmented Generation (RAG) assistant over a 149-lecture C++ DSA course: videos transcribed with Whisper, 1,255 chunks embedded with all-MiniLM-L6-v2 into a Qdrant vector database, and hybrid retrieval that returns answers grounded in lecture content with clickable YouTube timestamp links.

  • FastAPI endpoints (/query, /search, /health) integrating the Gemini API for answer synthesis, with an extractive fallback.
  • Chat-style web UI and 34 unit and integration tests using Pytest.
Python FastAPI Qdrant Gemini API Whisper Pytest

🛂 Full Stack Project

Passport Automation System

A full-stack web application automating the passport application and verification process, reducing manual processing time. Features a police verification workflow, admin dashboard for streamlined approval management, automated expiry notification system, real-time application status tracking, and AI-based document validation for document correctness.

  • Online passport application portal (PassportEase) with separate citizen, admin and police portals, a 6-step application wizard, document preview and real-time status tracking; deployed on Vercel with a Supabase REST API backend.
  • Sequential 5-step verification workflow (admin document review, police verification, final admin approval, passport issuance) with watermarked document uploads, row-level security, multilingual support and an AI support chatbot.
